## Catppuccin Mocha Hyprland rice

Dotfiles for [Jakub](https://github.com/JakubZ0)

Please feel free to copy any config file or a script!

I use [YADM](https://yadm.io/) for dotfiles managment.


### Software
Category | App used
:--- | :---
bootloader | systemd-boot
os | arch
wm | hyprland
bar | waybar
terminal | kitty
shell | zsh
terminal file manager | yazi
graphical file manager | nautilus
runner | fuzzel
editor | [neovim](https://github.com/JakubZ0/nvim)
notification daemon | swaync
browser | zen-browser
theme | catppuccin mocha
